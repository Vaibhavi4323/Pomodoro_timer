# ⏱️ Pomodoro Timer

A visually engaging **Pomodoro Timer web application** designed to help users stay focused and productive using the Pomodoro Technique. The app includes a modern UI, real-time clock display, animations, customizable work/break durations, and audio notifications.

---

##  Features

-  Real-time clock display (12-hour format with AM/PM)
-  Pomodoro focus timer
-  Customizable work & break durations
-  Audio notification when a session ends
-  Animated sparkles and watcher animation
-  Clean and modern UI
-  Fully responsive design
-  Runs completely in the browser (no backend required)

---

##  Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling and animations  
- **JavaScript (Vanilla JS)** – Timer logic and interactivity  
- **Lottie Animation** – Animated visuals

##  How to Run the Project

### Option 1: Open in Browser
1. Clone or download the repository
2. Open `index.html` in any modern web browser

### Option 2: Using VS Code Live Server (Recommended)
1. Open the project in VS Code
2. Install the **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**
